# Vídeo de cinco minutos

La presentación final está en `index.html` y el texto cronometrado en
`guion.md`. Ambos están sincronizados en ocho bloques que suman 5:00.

Controles del HTML: flechas o espacio para avanzar, `N` para notas y `F` para
pantalla completa.

Las cifras se refieren al corpus con fecha de corte **30 de junio de 2026**.
El ejemplo de variantes nominales de Navantia se presenta como una limitación
de resolución de identidad del comprador: no implica duplicación de
procedimientos y no se corrige con fuzzy matching sin evidencia adicional.
