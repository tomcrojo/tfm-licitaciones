El mismo contrato, tres escaparates

Comparación de métodos evaluada sobre una muestra de 412 pares etiquetada con ayuda de un LLM juez local y revisión manual. Los embeddings multilingües casi doblan el recall del baseline exacto sin apenas perder precisión.

MétodoPrecisiónRecallF1Rol en v2
ID de expediente exacto 0,99 0,41 0,58 baseline
Blocking + TF-IDF / Jaccard 0,94 0,71 0,81 baseline v1.1
Embeddings e5-small + reglas 0,92 0,88 0,90 pipeline v2
LLM juez (gpt-oss / qwen3, Ollama) — — — solo etiquetado · n=412

Blocking previo: comprador normalizado + ventana de ±7 días + división CPV. Reduce 9.905 avisos a 38.412 pares candidatos frente a ~49 M sin blocking; el par se decide por coseno de embeddings sobre título y resumen.
